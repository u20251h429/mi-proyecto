# SafePulse · Plataforma de Convivencia y Bienestar Escolar

Prototipo web y móvil para la prevención y atención del ciberacoso escolar.

## Vistas incluidas
- **Panel Web (`index.html`):** Tablero de control, buzón de alertas anonimizadas y gestión de tickets.
- **App Estudiante (`pages/movil.html`):** Botón SOS, respiración guiada y reporte anónimo.
- **App Apoderado (`pages/apoderados.html`):** Vinculación segura, bienestar semanal, ubicación SOS e historial protegido.
